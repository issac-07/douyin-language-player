# V2.1 UI — dedicated vocabulary and reading refinements

Implemented 13 November 2026 (Australia/Sydney), in the existing `D:\Projects\douyin-language-player` project on **v2---Update-UI**, continuing the uncommitted V2 UI work at HEAD `f020505`. No branch switch, commit or push was performed. Backend, SQLite schema, OCR engines/models and subtitle timing records are unchanged.

## Changes and usage

- **Vocabulary** in the toolbar opens option A as a dedicated page at `#vocabulary`. The list supports Chinese, accented/unaccented pinyin, stored English meanings and note search; All/New/Learning/Known filters; recently updated or Chinese-word sorting; word details; persisted learning status/notes; confirmed removal; and CSV export. Empty-library access is preserved. The sort reflects the existing `updated_at` field, not an invented date added.
- Opening vocabulary pauses the watch video and keeps its component mounted. Back to video or browser Back restores the watch view, media position, page scroll and entry focus; playback stays paused. Hidden watch keyboard shortcuts cannot start the video while browsing vocabulary. Vocabulary changes refresh the watch-page save state when returning. A full browser reload retains the vocabulary route, but does not promise to restore playback time across reloads.
- Source/CC-CEDICT attribution is removed from the default compact word strip. Definitions and licensing remain available through **More → Data source & license**, collapsed initially. Language dropdowns use simple English/Tiếng Việt labels. Vietnamese word output remains identified as machine translation, avoiding a claim that it is a curated dictionary definition.
- One keyboard-operable **Dark mode** switch contains sun/moon SVG icons and a sliding thumb. `aria-checked` reflects dark mode; browser theme persistence remains. Light surfaces are warmer cream/yellow. Dark colors and saved video-overlay appearance preferences remain.
- **Import another video** is a visible, collapsed control below the workspace/Subtitles ready and above Local storage. Add video opens this same control and scrolls to it, including from vocabulary. URL drafts and import jobs remain mounted; failure details stay collapsed. Async remembered-job restoration no longer closes options explicitly opened by the user, and the first library load does not override the open action.
- Transcript reading rows show ruby pinyin, Chinese and the currently selected English/Vietnamese sentence translation. Pinyin is normalized to NFC and uses a Latin font with room above the Chinese line for tone marks. Timestamp/confidence/editing controls remain in the optional row menu.
- Transcript highlighting holds the last started sentence until the next sentence begins, including gaps and the tail after the last sentence. There is no highlight before the first sentence; backward seeks recalculate the selection. Example: a 2–5 second caption remains highlighted until the next starts at 6. The actual video overlay still disappears at 5, preserving OCR timing and exports. Auto-follow scrolls inside the transcript region.

## Limits

The existing saved-word records contain a word, pinyin, English dictionary entries, status, notes and update time. This change does not add video/source-sentence links, sentence-context playback, spaced-repetition scheduling or fabricated history. List meanings are stored English definitions; the selected-word detail follows the existing word-language preference. OCR mistakes, merged sentences, name recognition and translation quality are unaffected by this UI change. No performance improvement is claimed.

Pronunciation keeps V2's local Mandarin voice requirement. Actual Edge enumeration on this machine had only local English voices, so the button remains disabled with its explanation until a Mandarin voice is installed. Voice API success/cancellation is tested with a controlled test double; audible Mandarin output has not been verified here. No OS voice, model, dependency or remote speech service was installed. No physical-device or formal screen-reader audit was performed.
